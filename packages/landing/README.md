# @decrity/landing

Decrity marketing landing page, standalone from the dashboard.

## Development

```bash
# From root
pnpm landing:dev

# Or directly
pnpm --filter @decrity/landing dev
```

## Build

```bash
pnpm --filter @decrity/landing build
```

## Tech Stack

- React 18
- Tailwind CSS
- shadcn/ui (Button only, so far)
- Vite
