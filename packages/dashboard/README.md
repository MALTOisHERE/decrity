# @trustlayer/dashboard

TrustLayer Web Dashboard - React app for viewing threat history and managing settings.

## Development

```bash
# From root
pnpm dev

# Or specifically
pnpm dashboard:dev
```

## Build

```bash
pnpm build
```

## Features

- Dashboard overview with statistics
- Threat history log
- User settings management (TODO)
- Weekly reports (TODO)

## Tech Stack

- React 18
- React Router v6
- TanStack Query
- Tailwind CSS
- Vite
