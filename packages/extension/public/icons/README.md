# Extension Icons

Place icon files here:

- `icon-16.png` - 16x16 pixels
- `icon-32.png` - 32x32 pixels
- `icon-48.png` - 48x48 pixels
- `icon-128.png` - 128x128 pixels

Icons should feature a shield design representing security/protection.

For development, you can use placeholder icons or generate them using:
- Figma/Sketch
- Online icon generators
- AI image generation tools

Recommended colors: Blue (#0ea5e9) for brand color
